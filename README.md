### What I Build

#### 📈 Financial Automation & Quant Infrastructure
* **[mt5-tradebot-api](https://github.com/Itszeeshanrajput/mt5-tradebot-api)** — High-throughput REST API for MetaTrader 5. Provides programmatic order execution, position risk management, telemetry, and strategy backtesting.  
  *Stack:* Python, FastAPI, MetaTrader 5, Redis, Pandas

* **[TradeEngine](https://github.com/Itszeeshanrajput/TradeEngine)** — Multi-account automated forex trading platform with live browser dashboard, automated risk controls, and pluggable indicator strategies.  
  *Stack:* Python, Flask, WebSockets, SQLite, Chart.js

#### 🔌 Firmware & Embedded Systems
* **[mobile-firmware-internals](https://github.com/Itszeeshanrajput/mobile-firmware-internals)** — Comprehensive engineering reference on modern mobile SoC bootloaders, partition maps, Emergency Download Modes (EDL / BROM) * **[wafford](https://github.com/Itszeeshanrajput/wafford)** recovery toolchains.
  *Stack:* ARM64, Qualcomm EDL 9008, MediaTek BROM, AVB 2.0, UFS/eMMC

* **[wafford](https://github.com/Itszeeshanrajput/wafford)** — Modern terminal UI (TUI) framework for 802.11 wireless security auditing, beacon monitoring, PMKID capture, and GPS wardriving export.  
  *Stack:* Python 3.12, Textual, Scapy, SQLite, Hashcat

* **[Drever](https://github.com/Itszeeshanrajput/Drever)** — Universal ESP32-S3 research firmware for 802.11 packet inspection, frame analysis, and lightweight web-based controls.  
  *Stack:* C++, ESP-IDF, PlatformIO, FreeRTOS

* **[esp32_nat_router](https://github.com/Itszeeshanrajput/esp32_nat_router)** — Hardware-accelerated NAT router and firewall implementation running on ESP32 microcontrollers.  
  *Stack:* C, ESP-IDF, Layer 3/4 Networking

#### 🖥️ Systems Internals & Diagnostics
* **[Win11-to-Win10-Transformer](https://github.com/Itszeeshanrajput/Win11-to-Win10-Transformer)** — Low-level Windows customization engine with 40+ atomic NT registry modifications and automatic system restore snapshots.  
  *Stack:* C#, .NET, Windows Registry APIs

* **[fusion-stress-tester-pro](https://github.com/Itszeeshanrajput/fusion-stress-tester-pro)** — Hardware diagnostic utility for stress-testing multi-core CPUs, system RAM, GPUs, and disk I/O with thermal telemetry.  
  *Stack:* Python, CustomTkinter, psutil

* **[SeedphraseScout](https://github.com/Itszeeshanrajput/SeedphraseScout)** — Educational blockchain engine demonstrating the computational infeasibility of seed phrase brute-forcing through live diagnostic workers.  
  *Stack:* Node.js, Worker Threads, EVM RPC, Cryptography
